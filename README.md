Useful Definitions:
Response Variable : The variable you want to explain, predict, or compare.
Examples: Plasma cortisol, Weight, Length, Monoaminergic activity


Predictor Variable: A variable that might influence or explain changes in the response variable.
Examples: Age, Sex, Treatment


Fixed Factor : A categorical variable whose specific levels are of direct interest and are deliberately chosen by the researcher.
Examples: Sex, Fishing treatment, Country
You are interested in comparing these specific groups.


Random Factor: A categorical variable whose levels are not the main focus of the study but may introduce variation in the data.
Examples: Sampling day, Tank, Site, Observer, Fish ID (for repeated measurements)
These factors are usually included to account for variability rather than to compare the groups themselves.
